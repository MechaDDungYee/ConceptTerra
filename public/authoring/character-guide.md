# 콘셉트테라 TRPG 캐릭터 JSON 제작 가이드

이 가이드는 개인 제작실 또는 세션에서 불러올 **캐릭터 전체 파일**을 만드는 방법입니다. 홈페이지에서 `example-character.json`과 `reference.json`을 함께 내려받으면 AI가 사용할 예제와 실제 검증 규칙을 확보할 수 있습니다.

## 파일 구조

| 키 | 내용 |
| --- | --- |
| `format` | 반드시 `"conceptterra-character"` |
| `version` | 반드시 정수 `1` |
| `character` | 캐릭터 시트와 일러스트를 담는 객체 |
| `passives` | 패시브 최대 8개. 없으면 `[]` |
| `conceptTools` | 개념 도구 최대 10개. 없으면 `[]` |
| `cards` | 패시브나 개념 도구가 참조하는 제작 카드. 없으면 `[]` |

UTF-8 JSON 객체 하나로 저장합니다. 코드 펜스, 주석, 끝 쉼표를 넣지 않습니다. 업로드 파일 최대 크기는 1,200,000바이트입니다.

## 캐릭터 시트

| `character` 필드 | 입력 규칙 |
| --- | --- |
| `name` | 이름. 최대 36자 |
| `country` | `"중앙국"` 또는 `"제1국"`~`"제9국"` |
| `status` | `"비시민권자"`, `"월정커"`, `"하위층 시민"`, `"중산층 시민"`, `"고위층 시민"` 중 하나 |
| `wall` | 월정커라면 `"제4국"`~`"제8국"` 중 하나. 나머지는 `""` |
| `activityLocations` | 활동지 태그 배열. 없으면 `[]`. 선택지는 규칙 목록의 `ruleOptions.locationTags`를 참고 |
| `job` | 직업. 최대 36자 |
| `goal` | 목표. 최대 180자 |
| `concept` | 개념 능력·의체 설명. 최대 180자 |
| `stats` | **근력, 민첩, 체력, 지능, 감각, 의지** 순서의 정수 6개. 각각 0~100, 합계 300 |
| `mind` | 시작 정신력. 0~100 사이의 정수. 캐릭터 시트 화면에 입력란이 없어도 파일에는 필요 |
| `art` | 일러스트 슬롯 객체. 이미지가 없다면 반드시 `{}` |

전투 능력치는 `stats`에서 계산됩니다. 최대 체력, 이동력, 행동 수를 별도 필드로 작성하는 대신 기본 능력치를 조정하세요.

## 정신력 변동 조건

캐릭터 파일 최상단의 선택 배열 `mindRules`에 정신력 변동 조건을 넣을 수 있습니다. 규칙이 없다면 생략하거나 `[]`를 사용합니다. 효과는 `kind:"mind"`(증가)와 `kind:"drain"`(감소)만 허용하며, 각각 최대 8개입니다. `to`는 항상 `"self"`입니다. 패시브와 같은 이벤트·조건·연산 형식을 사용합니다.

예를 들어 `{"kind":"mind","when":"turnStart","to":"self","amount":3}`은 턴이 시작될 때 자신의 정신력을 3 회복합니다. 효과의 `flow`, `condition`, `amountExpr`로 조건과 수치를 설정할 수 있고, 제작 카드를 참조하면 `cards`에 포함합니다.

## 일러스트

슬롯 키는 `형태.자세`입니다. 형태는 `normal`(기본), `crisis`(붕괴 직전), `concept`(붕괴), `awakened`(각성)입니다. 자세는 `idle`(스탠딩), `ready`(공격 준비), `attack`(공격), `hurt`(피격), `guard`(방어), `down`(전투 불능), `clash`(합), `shift`(변화 연출)입니다.

예를 들어 기본 스탠딩은 `normal.idle`, 붕괴 연출은 `concept.shift`, 각성 스탠딩은 `awakened.idle`입니다. 값은 실제 JPEG·PNG·WebP 파일을 인코딩한 Base64 데이터 URL입니다. 슬롯당 데이터 URL은 최대 320,000자입니다. URL이나 파일 경로만 적으면 가져올 수 없습니다. 원본이 크다면 사이트의 일러스트 업로드 기능에서 압축한 뒤 캐릭터 전체 파일을 다시 내려받으세요.

## 패시브·개념 도구·카드 연결

- 패시브와 개념 도구는 각각 `name`과 `effects`가 필요합니다. 이름 최대 36자, 효과 1~8개입니다. `flavor`와 `notes`는 선택이며 각각 최대 300자입니다.
- `enabled:true`로 활성화, `enabled:false`로 비활성화 상태를 지정합니다. 효과 키, 이벤트, 대상과 수치는 카드·패시브·중첩 제작 가이드 및 규칙 목록을 따릅니다.
- 효과가 제작 카드를 ID로 참조한다면 그 카드를 `cards`에 포함하세요. 참조 카드가 또 다른 제작 카드를 참조하면 그것도 포함합니다. 가져올 때 카드 ID와 효과의 참조 값이 함께 바뀝니다. 규칙 목록의 기본 카드 ID는 그대로 사용할 수 있습니다.
- 이 파일의 `cards`는 패시브·개념 도구 참조용이며, 플레이어 카드 보관함과 전투 덱은 각 메뉴에서 별도로 관리합니다. 사용자 제작 중첩은 중첩 파일로 옮깁니다.

## 가져오기와 확인

1. 개인 제작실 또는 세션의 **캐릭터 → 캐릭터 파일 → 캐릭터 전체 업로드**를 엽니다.
2. `example-character.json` 또는 작성한 파일을 선택합니다.
3. 교체 확인 창에서 진행합니다. 캐릭터 시트, 그림, 패시브와 개념 도구가 파일 내용으로 교체됩니다. 현재 캐릭터가 전투에 참여 중이면 전투가 끝난 뒤 가져옵니다.
4. 시트, 패시브 활성화 상태, 개념 도구 장착과 일러스트를 확인합니다. 로그인 계정의 캐릭터 목록에 남기려면 캐릭터 탭에서 계정에 저장합니다.

AI에 작성 요청을 할 때는 **이 가이드 + 캐릭터 예제 JSON + 규칙 목록 JSON**을 전달하고, `stats`의 합계와 참조 카드의 ID를 검증한 뒤 업로드할 JSON만 출력하도록 요청하세요.
