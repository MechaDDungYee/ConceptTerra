# 이루어질 행동 이펙트

현재 게임에 등록된 행동 이름과 타수에 맞춘 시각적 연출이다. 능력, 키워드, 피해량이나 세계관의 새 설정을 추가하지 않는다.

| 행동 | 타수 | 연출 |
| --- | --- | --- |
| 결말 예측 | 2 | 푸른 예측선 두 갈래가 대상에 수렴. 얇은 표적 괄호와 짧은 교차선. 2타는 선이 조금 더 강해진다. |
| 확신의 일격 | 2 | 금빛 관통 궤적과 밝은 펜촉형 끝선. 2타의 궤적과 적중 파편을 강화. |
| 계획 수정 | 3 | 1타부터 3타까지 수정선이 한 줄씩 늘어난다. 타수별로 교차 방향과 적중 잔선이 바뀐다. |
| 결말 주석 | 1 | 금빛 주석 괄호, 기록 리본, 작은 문서 조각형 잔선이 대상 주변에서 펼쳐진다. |
| 이루어질 · 회피 | 대응마다 | 회피 성공 판정에만 비껴가는 푸른 잔선과 흐려지는 예측 괄호. 수비 대기에는 성공 효과를 재생하지 않는다. |
| 결말 주석 · 개념 폭주 | 3 | 타수가 늘수록 기록 리본과 금빛 조각이 많아지며, 마지막 타수에 교차 기록선으로 수렴한다. |

이루어질이 참여하는 충돌에는 짧은 금빛·백색 불꽃을 추가한다. 다른 팀원의 행동에는 적용하지 않는다.

## 적용 방식

- `battle-effects.js`의 고해상도 Canvas 연출. 기기 픽셀 비율을 반영하고 크기는 화면의 개체 크기에 비례한다.
- 현재 초안은 별도의 PNG 이펙트 이미지나 프레임 시트가 아니라 실시간으로 그리는 선·곡선·파편이다.
- `battle-playback.js`의 기존 공격 타수, 피해, 충돌, 회피 판정 기록만 사용한다. 확률 판정이나 피해량을 다시 계산하지 않는다.
- 공격 파형 판정 후 발사 효과, 실제 양수 피해 적용 후 적중 효과. 지속 피해, 0 피해, 회피된 타격에는 공격 적중 효과가 없다.
- 피해 숫자보다 아래에 표시하며 마우스·터치를 가로채지 않는다. 재생 종료 시 Canvas와 프레임 예약을 정리한다.
- 전투 난수 함수를 사용하지 않는다. 움직임 줄이기 설정에서는 이동을 축약하고 짧게 사라진다.

검증: 전투 엔진 26개 검사, 행동별 전체 타수, 실제 회피 성공, 개념 폭주, 다른 인물 제외, 화면에 그려진 픽셀, 종료 후 정리와 컴퓨터·가로형 휴대폰 화면 확인.
