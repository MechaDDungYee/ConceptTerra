# 게임 연결 기록

2026-10-09: 단일 이미지 모션 19장을 전투 재생에 연결.

- 이루어질: 17장, 이루어져: 2장.
- 실제 그림의 좌우 중심을 배우 위치에 맞춤. 반대 방향에서도 중심을 유지.
- 기본 SD와 동일한 픽셀 배율 적용. 각 자세의 발 기준점으로 높이를 보정.
- 미제작 자세는 기본 SD로 대체. 예전 큰 머리 모션으로 대체하지 않음.
- 이미지 해독 후 교체. 전투 판정과 피해량 계산 변경 없음.
- 제작 manifest의 applied 필드는 제작 시점 기록. 현재 게임 연결 상태는 이 문서와 runtime.js 기준.
- 일부 자세의 머리 크기와 발 기준점은 여전히 추가 미술 검수 필요.
