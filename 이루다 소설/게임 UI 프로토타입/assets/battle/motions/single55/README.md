# 단일 이미지 모션

파츠 합성 없이 한 자세당 한 장의 투명 PNG로 제작.

- 이루어질: 17 / 17 자세 저장.
- 이루어져: 17 / 17 자세 저장.
- 나머지 팀원: 아직 제작하지 않음.
- 전체 34 / 143 저장.
- 실제 원본 크기: 1086 × 1448. 요청한 2172 × 2896이 전달되지는 않았으며 임의 업스케일하지 않음.
- PNG 투명 배경과 실제 크기 검증 완료.
- 동일 픽셀 배율로 표시하며 발 기준점은 근사치. 인체 비율의 완전 일치는 보장하지 않음.
- 이루어질 이동·충돌 및 이루어져 공격·피격 머리 축소 수정. 이루어져 1타 다리 겹침과 소매 문양 수정.
- 이루어질 1스킬 후속 자세 펜촉 및 이루어져 일부 코트 끝 여백 추가 검수.
- 이루다 1팀 전구 문양을 참조하여 소매 패치 제작. 작은 자수의 정확한 재현은 별도 검수 필요.
- 연속 프레임 애니메이션이 아닌 주요 자세 이미지. 실전 게임 연결 완료.
- 첫 두 장 프롬프트: prompts.json, 추가 프롬프트: additional-prompts.json 및 각 자세 JSON.
