# 전투 모션 재제작 v2

- 9명, 143개 핵심 포즈. 기준은 각 캐릭터의 승인된 작은 머리 SD 원본이다.
- 2×2 가상 그리드로 묶음을 제작하고, 붙어 나오거나 도끼가 원본 경계에 잘린 9개 컷은 단일 포즈로 재제작했다.
- 최종 투명 PNG 캔버스는 1536×2048이며, 모든 실루엣이 사방 15% 안전 영역 안에 들어가는지 검사했다.
- `native-v2`에는 확대하지 않은 원본 분리 컷을 보존한다. 최종 캔버스 크기가 실제 원본 세부 해상도라는 뜻은 아니다. 미리보기에서 실제 원본 크기를 확인할 수 있다.
- 단일 컷과 묶음 컷의 원본 셀 해상도 차이를 보정하고, 캐릭터별 공통 배율을 적용했다. 자세마다 높이를 같게 늘리거나 줄이지 않았다.
- 기준점은 실루엣 하단의 초안 기준점이다. 공중 자세, 효과가 발보다 낮은 자세는 애니메이션 연결 전 발바닥 기준점 조정이 필요하다.

## 확인한 사항

- 캐릭터별 비교 이미지 9장을 열어 머리와 몸, 팔의 연결, 손과 장비를 검토했다.
- 원본 외곽에서 잘린 컷은 0개다.
- 143개 투명 배경, 파일 크기, 원본 링크, 안전 영역 검사 통과.
- 1440×900 및 844×390 화면에서 9명 전체 이미지 로딩과 미리보기 표시 검사 통과.
- AI 스킬에 그리드, 승인 SD 비율 유지, 손 방향, 원본 해상도 기록 및 재제작 규칙을 반영했다.

## 보장하지 않는 사항

이미지 생성은 동일한 리깅 모델을 변형하는 방식이 아니므로 모든 컷의 머리·신체 비율이 픽셀 단위로 절대 동일하다고 보장할 수 없다. 머리카락, 옷 주름, 손가락 등에는 컷별 차이가 남을 수 있다. 자동 검사는 해부학적 정확성을 증명하지 않으며 모든 컷의 검수 표시는 유지했다. PNG는 무한 확대 시 화질 손실을 피할 수 없다.

현재 결과는 연속 프레임 애니메이션이 아니라 핵심 포즈다. 사용자의 연결 요청에 따라 게임 전투 재생에 v2 포즈를 연결했다. v1 원본은 보존했다.

## 전투 연결

- `battle-motions.js`는 스킬명과 실제 타수로 해당 컷을 선택한다. 없는 컷은 기본 SD로 돌아가며 임의의 다른 스킬 컷을 보여주지 않는다.
- 이동, 충돌, 충돌 승리·패배, 피격, 실제 회피·방어, 반격, 각 타수와 개념 폭주를 기존 전투 재생 기록에 연결했다.
- 수비 대기에는 충돌 준비 자세, 실제 성공한 회피와 방어에는 수비 포즈를 사용한다. 반격은 기존 엔진의 1회 대응 기록을 따른다.
- 캐릭터별 공통 표시 배율은 승인 SD와 충돌 승리 컷의 실루엣 높이로 보정한다. 포즈마다 임의로 크기를 맞추지 않는다. 발 위치는 여전히 실루엣 기준의 초안이므로 실제 연속 애니메이션 제작 시 정밀 검수가 필요하다.
- 새 모션은 이미지를 먼저 읽은 후 교체하며, 로딩 실패 시 기본 SD로 돌아간다. 적에게는 아군 모션을 적용하지 않는다.
- 전투 엔진 파일과 피해·파형 판정은 변경하지 않았다.
- 전투 엔진 26개 검사 및 컴퓨터·휴대폰 화면의 모션, 충돌, 회피·방어·반격 재생 검사 통과.
