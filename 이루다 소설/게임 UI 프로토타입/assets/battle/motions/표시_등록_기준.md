# 전투 이미지 표시 기준

2026-10-08. 승인된 이루겠네 SD와 동일한 스탠딩 규격을 기준으로 한다.

- 스탠딩 원본은 768 × 1024, 머리 위 기준 y=64, 발 기준 y=964이다. 기준 신장 구간은 900px이다.
- 스탠딩과 모션 모두 이미지 전체 사각형의 밑면 대신 등록된 발 기준점을 전장의 접지점에 맞춘다.
- 대기 스탠딩 표시 배율은 1024 / 900이다. 모션은 기존 캐릭터별 공통 배율에 같은 등록 배율을 적용한다.
- 모션 캔버스는 1536 × 2048, 기존 발 등록점은 [768, 1740]이다. 원본 PNG와 공유 배율은 보존한다.
- 준비 화면과 실행 화면 모두 같은 접지 원칙을 사용한다. 실행 화면의 카메라 확대는 연출이며 이미지 등록 배율 변경과 구분한다.
- 자세마다 외곽 높이를 다시 맞추지 않는다. 달리기나 웅크림이 낮아지는 것을 키 감소로 간주하지 않는다.
- 기존 생성 이미지의 모션 등록점은 실루엣 하단을 바탕으로 한 근사치이다. 무기 끝과 발바닥이 다른 높이인 그림, 실제 해부 비율이 달라진 그림은 추가 수동 검수 또는 재제작이 필요하다. 이 조정이 모든 이미지의 해부학적 동일성을 보장하지는 않는다.
