# 5.5-head SD redraw review

Target: 5.5 head units, measured crown to chin against crown to sole.
Selected review results: approximately 5.2-5.7 visible-head units, not an exact anatomical guarantee.
All nine selected native PNGs are 1086x1448 with transparent alpha. See preview.html.
Hair ornaments and isolated hair spikes are excluded; the normal hair cap is included.
The hidden skull contour cannot be measured precisely from a flattened PNG.

Initial generated files ending in `_native.png` are drafts, not verified 5.5-head results.
Corrected files will be saved separately. Original SD and game references remain untouched
until proportion review is complete. Old attack poses do not inherit these proportions.

Built-in image generation is used. Native resolution and full prompts are recorded
in `selection-records.json`; generation-records.json preserves earlier drafts.
Enlarging a bitmap does not restore native detail.
