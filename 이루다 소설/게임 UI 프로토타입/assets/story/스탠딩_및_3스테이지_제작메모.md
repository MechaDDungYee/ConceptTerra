# 펜타R 스탠딩과 0장 3스테이지

## 공통 스탠딩 프롬프트

기존 `펜타R_컴퍼니_다목적팀_4인방_컨셉아트.png`를 디자인 기준으로 사용한다. 세미 리얼리스틱한 한국 다크 판타지 게임 일러스트. 단독 전신, 차분한 대화용 자세, 자연스러운 인체 비율, 같은 붉은 방호복, 오른쪽 팔 바깥에 올리브색 오각형 펜타R 패치. 배경은 완전히 투명하고 바닥·그림자·검은 배경·후광·글자·패널은 넣지 않는다. 원본 PNG의 투명도를 유지한다.

- 하자드: 성인 남성, 헝클어진 검은 머리, 강한 체격, 신형 반면 방독면, 낡고 긁힌 붉은 방호복. 사슬이 감긴 방망이를 어깨에 걸친 자세.
- 바이오: 작은 체구의 성인 여성 조종사, 짧은 어두운 머리, 신형 방호복과 열린 후드, 헤드셋, 태블릿. 어린아이처럼 표현하지 않는다.
- 드링크: 성인 여성, 긴 갈색 머리, 구형 붉은 방호복. 원형 렌즈와 호스가 있는 구형 방독면, 술 플라스크.
- 시가렛: 큰 체격의 성인 남성 팀장, 구형 붉은 방호복과 구형 방독면. 방독면의 담배 구멍과 여닫는 회색 덕테이프 조각, 담배.

스탠딩 파일: `standing/pentar_hazard.png`, `pentar_bio.png`, `pentar_drink.png`, `pentar_cigarette.png`.

## 배경 프롬프트

공통: 인물과 사람 실루엣 없는 1920×1080 세미 리얼리스틱 페인터리 배경. 대화용 스탠딩을 겹칠 전경을 비워 둔다. 글자·워터마크·테두리 없음. JPG는 1MB 이하.

- 비행정 내부: 공간 확장이 적용된 넓은 산업용 수송선 객실, 낡은 금속과 리벳, 좌우 안전벨트 좌석, 중앙 통로, 앞쪽의 비어 있는 조종석 두 자리, 계기판, 어두운 산업 지대 하늘을 보여주는 창문. 호화로운 함선이 아닌 작업용 공간.
- 격납고: 거대한 금속 보, 기계 정비 설비, 기름 묻은 콘크리트 바닥과 작업등. 대형 버스 크기의 도깨비가 주차되어 있다. 네 개 정도의 옆 창문과 낮은 승하차 문, 문을 가리지 않는 짧은 무한궤도, 앞쪽 장애물 제거 금속판. 거대한 전쟁 병기로 확대하지 않는다.
- 도깨비 내부: 10명용 공간 확장 버스. 넓은 중앙 통로, 옆면에 등받이가 닿는 좌우 좌석, 맨 뒤에는 정중앙의 닫힌 문과 좌우 각각 두 자리의 앞을 향한 좌석. 뒤 창문 없음. 붉은 좌석과 절제된 금속·목재 마감.

## 화자와 진행 규칙

- 2스테이지의 대사와 뒤따르는 서술은 분리하되 원문 문장은 생략하지 않는다.
- 명찰을 읽거나 이름을 확정하기 전에는 이름 `???`, 이루리 본인은 자신의 이름을 알기 전 `나`.
- 누님과 아우는 지칭은 알려졌으나 본명이 아니므로 `누님?`, `아우?`. 월정커라는 소속이 대사로 확인된 뒤 소속을 표시한다.
- 독백과 지문은 소속·이름 칸을 숨긴다. 인물의 실제 화자 ID와 화면에 공개할 이름을 별도로 저장한다.
- 사망한 월정커의 스탠딩은 이후 대화 화면에 다시 나오지 않는다.
- 바이오는 2스테이지에서 조종석에 있으므로 외부 대치 화면에 나오지 않는다. 드링크의 화장실 안 대사는 음성만 표시한다.
- 3스테이지는 원문 첫 구간의 비행정 탑승부터 팀원 소개, 격납고 도착, 도깨비 출발과 이루리의 자기 의심까지 137개 문단 전체를 포함한다.
- 원문에 남은 이미 타버린 필라멘트 언급은 대사로 보존하되 초기 이루리 스탠딩은 빛과 개념의 필라멘트 하나만 있는 기존 이미지를 사용한다.
- 원문별 화자 배정은 `tools/build-story-stage3.cjs`에 명시한다. 생성된 발표용 데이터는 `story-stage2-presentation.js`, `story-stage3-data.js`에 저장한다.

## 스탠딩 배치와 키 보정

- 이루리가 대답할 때 이루어질로 대화 상대를 초기화하지 않는다. 현재 대화 상대를 유지하며 인물의 등장·이탈은 장면별로 지정한다.
- 이루도록이 붙잡는 지문, 효과음, 이루리의 감사, 이루도록의 답변, 명찰 확인까지 이루리·이루도록의 배치를 유지한다.
- 원고 기준 키: 이루어질 171cm, 이루어져 135cm, 이루어라 175cm, 이루소서 177cm, 이루게나 181cm, 이루도록 192cm, 이루려나 168cm, 이루겠네 165cm. 이루어도는 신체 크기가 변하지만 스탠딩 연출에서는 최신 사용자 지정 200cm로 고정한다. 원고의 키 설정을 변경하는 것이 아니다.
- 이루리·펜타R 인원·월정커 남매의 정확한 키는 확인한 문서에 없으므로 확정 설정으로 추가하지 않는다. 화면 연출에만 임시 기준을 사용한다: 이루리 180, 하자드 185, 바이오 155, 드링크 170, 시가렛 190, 누님 175, 아우 180cm. `standing-layout.js`의 `confirmed:false`로 구분한다.
- 그림별 투명 여백을 측정해 실제 인물의 높이를 맞추고 발 기준선을 공유한다. 이미지를 세로로 늘이거나 찌그러뜨리지 않는다.
- 이루리는 화면 높이의 110%를 차지하는 실제 그림 높이를 고정 기준으로 사용한다. 인물 조합에 따른 자동 카메라 확대·축소는 사용하지 않는다. 다른 스탠딩의 실제 그림 높이는 `110% × 표시용 키 / 이루리 기준 180cm`로 계산한다. 이루리의 180cm는 화면 비율 기준이며 확정 신체 설정이 아니다.
- 일반 인물의 발 기준선은 화면 위에서 140% 위치로 고정한다. 이루어져만 추가로 화면 높이의 7%만큼 올린다. 실제 신체 키는 그대로 유지한다. 양쪽 스탠딩 중심은 화면 폭의 34%와 66%다. 하반신 일부는 화면 밖으로 나가며 투명 여백은 별도로 보정한다. 이루어도 스탠딩은 이루리 높이의 약 1.11배다.

## 1장 1스테이지 및 지도 경로
- 메인 연방 지도와 장 내부 지도 모두 실제 노드 좌표를 순서대로 연결한다. 열린 경로는 금색 실선, 잠긴 경로는 회색 점선이다.
- `이루다 2획 - 헌신을 이루다.md`의 첫 구분선 이전 185개 문단을 1장 1·2스테이지에 나눠 원문 생략 없이 사용한다. 1스테이지는 타워 출발부터 저택 앞까지 104개 화면이다. “하… 일단 들어가자.”부터 2스테이지를 시작하며 새 용병단 및 튜토리얼 장면을 포함해 125개 화면이다.
- 2스테이지는 집 방문, 심상 세계 진입, 무의식의 용병단, 전투 튜토리얼, 의뢰인과의 만남과 모닥불로 이어진다. 이루어도는 현실에 남으므로 심상 세계 스탠딩 및 선발·대기·교체 목록에서 모두 제외한다.
- 제이크 설리번과 셀타 마르틴은 기존 삽화의 외형을 참고한 투명 스탠딩을 추가한다. 정확한 키는 미확정이므로 두 사람 모두 화면 연출용 180cm 임시 기준이다.
- 인물 없는 의뢰인 저택 및 심상 세계 야영장 배경은 1920x1080 JPG로 저장한다.
- 아직 작성되지 않은 스테이지에서는 다른 장의 이야기를 대신 재생하지 않는다.
- 휴대폰 가로 화면은 대화창을 최대 화면 높이의 25%로 제한하고 긴 텍스트만 창 안에서 스크롤한다. 작은 인물의 얼굴을 가리지 않으며 전체 화면의 스크롤은 발생하지 않는다.

## 2026-10-06 UI 및 전투 튜토리얼
- 팀원별 로고 10개는 각자의 개념을 표현하는 그림형 투명 PNG로 새로 제작했다. `assets/logos/*_로고_v2.png`이며 기존 SVG 대신 실제 화면에서 사용한다. 이루어질은 기록과 모래시계, 이루어져는 꿈과 침구, 이루어라는 기계와 중력, 이루소서는 칼과 부서진 시계, 이루리는 단일 필라멘트 전구, 이루어도는 종이 가면과 주먹, 이루게나는 늑대와 도끼, 이루도록은 대칭 백화와 체스, 이루려나는 여우와 도화선, 이루겠네는 보호의 날개와 붉은 리본을 모티브로 삼는다. 로고 모티브는 능력 설정 추가가 아니다.
- 공격 아이콘은 넓은 칼날·두꺼운 가드·손잡이가 보이는 칼 실루엣으로 다시 제작해 PNG에 반영했다. 타수 숫자 배치는 유지한다.
- 편성 화면 및 이격 선택 화면의 전체 배경은 도깨비 내부이며, 각 인물 카드에는 개인 배경이 보인다. 출전 순서 화면에는 격납고 배경을 사용한다.
- 0장 3스테이지 격납고·도깨비 내부 배경은 07번·09번 기존 삽화를 참조해 재제작했다. 검은 리벳 장갑 버스, 낮은 승하차 발판, 부분 무한궤도, 넓은 내부 통로, 맨 뒤 2좌석-닫힌 문-2좌석과 호박색 조명을 유지한다. 1920x1080 PNG와 1MB 이하 JPG로 저장한다.
- 의뢰인의 무의식이 상상 속 용병단을 만들어 외부인을 배제한다. 이루어질은 일행이 상상에 방해되는 불순물과 같다고 설명하고 돌파를 지시한다. 이 전투는 의뢰인을 만나기 전에 발생한다.
- 튜토리얼은 21단계다. 편성, 적의 예고, 체력·정신력, 직접 선택·이동·카드·대상, 취소, 범위, 충돌, 누적 파형, 타수 파괴, 다른 아군 수비, 우선순위·추가 슬롯, 직접 턴 진행, 키워드·공명, 가방, 개념 폭주, 대기·교체, 실제 승리와 스토리 복귀를 다룬다.
- 실습 단계는 설명을 읽고 ‘실습 시작’으로 안내를 접은 뒤 실제 행동을 수행해야 다음으로 넘어간다. 안내는 다시 펼칠 수 있고 상태 변경 후에도 접힘을 유지한다. 패배 시 재도전 가능하다.
- 일반 더미 전투는 9명 중 선발 4명·대기 5명을 유지한다. 심상 세계 튜토리얼은 8명 중 선발 4명·대기 4명이다. 실제 이동·예약·충돌·효과·피해·가방 계산을 공용 엔진으로 수행한다. 튜토리얼 전용 용병의 낮은 위력 및 체력은 교육용 난이도이며 일반 전투 수치를 바꾸지 않는다.
- 튜토리얼 승리 후 중단된 2스테이지로 돌아온다. 전투 진입 전 더미 상태를 보관하고 종료·이탈 시 복구하여 용병이나 제외된 인원 설정이 일반 전투에 남지 않는다.
- 제작 프롬프트는 `assets/UI_이미지_교체_프롬프트.md`에 별도로 저장했다. 내장 이미지 생성 도구를 사용했다.

## 전투 SD 제작 기준
- 이루게나만 머리와 얼굴 주변 머리카락 부피를 추가 축소한 `06_이루게나_SD_v3.png`로 교체한다. 몸 높이·발선·도끼 위치는 유지하며 앞으로 이루게나 모션은 이 버전을 기준으로 한다. 다른 9명은 그대로 유지한다.
- 최신 변경: 머리가 작은 첫 수정본 `*_SD_v2.png`를 사용하며 뒤이어 생성한 머리 확대본은 적용하지 않는다. 앞으로는 5~6등신 정도를 목표로 하며 기존 3.5등신 지시는 폐기한다. 상세 기준은 `assets/battle/sd/SD_비율_기준.md`를 우선한다.
- 모든 SD는 768x1024, 동일한 900px 높이 및 발 피벗 (384,964), 표시 배율 1을 사용한다. 이루어져 0.83배·이루어도 1.15배 표시는 삭제한다. 가로 폭에 맞춰 인물 전체가 축소되는 방식을 사용하지 않는다.
- 1팀 10명의 기본 대기 SD는 `assets/battle/sd`에 개별 저장한다. 전투원은 9명이며 이루리는 관측용 별도 이미지로만 보관하고 출전하지 않는다.
- 기존 스탠딩의 얼굴, 머리 색, 1팀 유니폼 및 대표 소품을 유지하되 약 3.5등신, 큰 얼굴, 짧은 다리, 큰 부츠, 굵은 윤곽선, 단순한 면 음영으로 표현한다. 첨부 예시는 전투 SD의 표현 밀도와 용도만 참고하며 캐릭터 디자인이나 자세를 복제하지 않는다.
- 투명 PNG는 모두 512x768이고 발 기준선은 아래 30px 여백이다. JPG는 `jpg` 폴더에 1MB 이하로 저장한다. 이루어져는 작게, 이루어도는 크게 표시하되 전투 SD 크기는 화면 가독성을 위한 연출값이며 신체 설정 변경이 아니다.
- 이루겠네의 붉은 리본, 이루려나의 오른쪽 주황 눈과 머리 위 고글, 이루소서의 수염, 이루어도의 종이 가면, 이루게나의 도끼, 이루리의 단일 필라멘트를 유지한다. 과거 수감복·연구복·목장복 등은 기본 전투 SD에 사용하지 않는다.
- 전투에서만 `battle-sprites.js`의 SD 경로를 사용한다. 대화 스탠딩과 편성 일러스트는 변경하지 않는다. 이번 이미지들은 기본 대기 자세이며 공격·피격 애니메이션 시트가 아니다. 제작 프롬프트는 `assets/battle/sd/SD_제작_프롬프트.md`에 저장한다.

## 2026-10-07 머리 위 행동 슬롯 조작
- 아군·적군 머리 위 슬롯을 선택하면 해당 슬롯의 행동 카드를 표시한다. 충돌 예정 슬롯은 양쪽 카드와 승률을 함께 표시한다. 빈 슬롯에는 다른 슬롯의 카드를 대신 보여주지 않는다.
- 아군 슬롯을 선택한 뒤 손패를 클릭하거나 손패를 같은 유닛의 슬롯으로 끌어 놓으면 해당 슬롯의 대상 지정 상태로 들어간다. 장착된 슬롯 자체를 대상으로 드래그하면 기존 카드의 주 대상을 수정한다.
- 새 대상 지정 완료 전까지 기존 행동과 대상을 유지한다. 사거리·대상 조건 및 최종 결정 순서에 따른 기존 충돌 규칙을 사용하며, 수정하지 않은 다른 슬롯은 보존한다. 다른 슬롯에서 사용 중인 동일 손패 카드는 중복 장착할 수 없다.
- 적 슬롯은 조회 및 대상 지정에 사용하며 플레이어가 적의 카드를 편집하지는 않는다. 새 전투·다음 턴에서는 선택 슬롯을 초기화한다.

## 팀원 로고 단순화 지침
- 로고는 대표 도구나 소품 한두 개를 결합한 간결한 평면 일러스트로 제작한다. 첨부된 캐릭터 문장처럼 굵은 검은 윤곽선과 아이보리 및 제한된 강조색을 사용한다. 인물 초상, 과한 장식, 입체 금속 효과, 복잡한 테두리는 사용하지 않는다.
- 현재 사용하는 로고는 `assets/logos/*_로고_v3.png`다. 모두 512x512 투명 PNG이며 편성 및 전투에서 공통 사용한다. 이전 버전은 원본 보존용으로 남긴다.
- 이루어질: 책과 깃펜 / 이루어져: 수면 인형과 베개 / 이루어라: 렌치와 기어 / 이루소서: 칼과 부서진 시계 / 이루리: 단일 필라멘트 전구 / 이루어도: 종이 가면과 닫힌 펜던트 / 이루게나: 도끼와 구속 끈 / 이루도록: 체스 말과 백동백 / 이루려나: 기폭장치와 도화선 / 이루겠네: 보호의 날개와 붉은 리본.
