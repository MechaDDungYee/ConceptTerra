# 이루겠네 2D 메시 리그

`이루겠네_정면.png`는 정면을 바라보는 중립 자세의 투명 원화입니다. 긴 하체를 줄여 균형을 맞췄습니다.

`rig.json`은 텍스처, 메시 밀도, 관절 위치와 조절 범위를 담은 모델 데이터입니다. `rig.js`가 이 데이터를 읽어 연속 메시를 변형합니다. `preview.html`에서 머리 좌우/상하, 몸 기울임, 호흡, 머리카락 흔들림을 볼 수 있습니다. 머리 상하 변형은 목 위쪽에 한정해 가슴의 신축을 줄였습니다.

`parts/`에는 얼굴·목, 앞머리, 뒷머리, 제복 몸통, 양팔, 하체, 눈을 뜨고 감는 모습, 입을 열고 닫는 모습을 분리해 다시 그린 **초안**을 보관했습니다. `parts/preview.html`에서 각 파츠를 볼 수 있습니다. 팔과 겹치지 않게 소매를 제거한 몸통은 `torso-core.png`이며, 이전 `torso.png`는 비교용으로 남겼습니다. 각 PNG는 투명 배경이지만 원화와 크기·위치가 완전히 일치하지 않아 바로 겹쳐 사용할 수 없습니다. 개별 눈동자·흰자·눈꺼풀, 입 내부/입술, 팔꿈치·손목, 무릎, 가려진 어깨·목 연결부도 세부 리깅 단계에서 보정하거나 다시 나눠야 합니다.

## 좌표가 고정된 새 원화

`aligned_source/이루겠네_정렬원화.psd`와 `aligned_source/이루겠네_정렬원화.ora`는 위 초안과 달리 정면 원화의 동일한 1024×1536 좌표를 사용합니다. 34개 보이는 레이어에 눈 감기·입 열기 대체 그림 2개와 가려진 피부·제복·목의 보조 그림 3개를 숨긴 레이어로 넣었습니다. `aligned_source/layers/`의 개별 PNG도 모두 같은 크기이므로 위치 (0, 0)에 겹치면 맞습니다. 보이는 원화 픽셀은 분리 후 합성해도 차이가 0입니다.

`aligned_source/preview.html`에서는 레이어별 표시, 드래그 및 1px 단위 정렬, 원본 비교, 정렬값 내보내기를 할 수 있습니다. `aligned_source/이루겠네_레이어합성.png`는 검수용 합성본입니다. PSD는 Photoshop/Live2D Cubism용, ORA는 Krita/GIMP 등에서 레이어를 편집하기 위한 형식입니다.

### 큰 고개 회전용 원화

`aligned_source/head_turn/preview.html`에서 정면, 좌우 약 60도, 상하 약 25도의 다섯 기준 자세를 볼 수 있습니다. 상반신과 전신 보기를 전환할 수 있습니다. `head_turn/`의 `head_left_60.png`, `head_right_60.png`, `head_up_25.png`, `head_down_25.png`는 모두 1024×1536 캔버스에 놓인 머리·목 교체 그림입니다. 각 방향의 `*_back_hair.png`와 `*_face_bangs_neck.png`는 더 잘게 나눈 리깅용 파츠이며, 두 파츠를 같은 좌표에 합치면 해당 방향의 전체 머리 그림과 일치합니다. `body_without_head.png`와 교체 그림을 겹친 결과는 `preview_*.png`입니다.

PSD/ORA에는 이 회전 그림들을 숨긴 레이어로 넣었습니다. 특정 방향을 편집할 때는 정면 레이어를 잠시 숨기고 `turn_body_without_head`와 원하는 방향의 `turn_head_*` 레이어를 표시하면 됩니다. 전체 머리 레이어와 같은 방향의 분리 파츠는 동시에 켜지 마세요. 이들은 큰 각도에서 새로 드러나는 귀·옆얼굴·뒤통수·목을 제공하는 **키프레임 원화**이며, 중간 각도의 자연스러운 변형과 VTube Studio용 `.moc3` 제작은 Cubism Editor에서 따로 설정해야 합니다.

원본의 보이는 픽셀은 정확히 보존했지만, 가려진 어깨·얼굴 내부를 복원한 보조 그림은 단색으로 채운 작업용 바탕입니다. 큰 고개 회전이나 팔을 크게 들어 올리는 동작에는 해당 영역을 추가로 그려야 합니다. 눈·입의 대체 그림도 표정 리깅의 시작점이며 완성 애니메이션은 아닙니다.

이 파일은 자체 2D 메시 리그 형식입니다. Live2D Cubism의 `.moc3` 또는 VTube Studio 모델은 아닙니다. Cubism Editor에서 정렬된 다층 원화를 가져와 변형기·파라미터·물리 효과를 설정하고 `.moc3`로 내보내야 VTube Studio에서 불러올 수 있습니다. 현재 이 작업 환경에서는 Cubism Editor가 확인되지 않아 최종 내보내기를 수행하지 못했습니다.
