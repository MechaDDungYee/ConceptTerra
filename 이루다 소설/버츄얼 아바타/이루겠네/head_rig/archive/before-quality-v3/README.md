# 이루겠네 머리 중심 원화

기존 원화의 픽셀을 잘라 레이어로 배분한 파일이 아닙니다. 각 파츠를 별도 그림으로 만들고 2048 x 3072 좌표에 정렬했습니다. 이전 1024 x 1536 버전보다 가로·세로 해상도가 각각 2배입니다. 다만 원본보다 큰 부분은 보간되므로 새 디테일이 생성되는 것은 아닙니다.

## 레이어

아래에서 위로: `back_hair` (얼굴 뒤까지 채운 뒷머리), `face_blank` (눈·눈썹·입이 없는 얼굴과 목), `body` (팔과 다리를 포함한 통짜 몸체), `eyes_open`, `mouth_closed`, `shirt_front` (쇄골을 덮는 옷깃), `front_hair`입니다. `eyes_closed`, `mouth_open`은 각각 숨김 대체 레이어입니다. `face_neck_reference`는 표정이 합쳐진 이전 얼굴의 숨김 참고 레이어입니다. 같은 부위의 열린/닫힌 레이어를 동시에 켜지 마세요.

`source/`에는 축소·정렬 전 고해상도 원화가, `layers/`에는 공통 좌표로 정렬한 PNG가 있습니다. PSD와 ORA는 편집용 레이어 파일입니다. 종전의 큰 각도별 회전 그림은 이 파일들에 포함하지 않았습니다.

Cubism에서 열리는 기본 파일은 `이루겠네_머리중심_원화.psd`입니다. 확인용 `이루겠네_머리중심_원화_Cubism.psd`도 동일한 내용이며, `*_legacy.psd`는 가져오기 오류가 나던 이전 형식을 보관한 파일이므로 열지 마세요.

`preview.html`은 레이어 정렬을 확인하는 간단한 미리보기입니다. 좌우 12, 기울기 6, 상하 8 범위만 보여주며 실제 Cubism 리깅이나 VTube Studio용 `.moc3` 모델은 아닙니다. 실제 고개 회전은 편집기에서 이 원화를 바탕으로 리깅해야 합니다.

## Cubism 5.3에서 다음 작업

1. `이루겠네_머리중심_원화.psd`를 새 모델로 가져옵니다. 눈·입 없는 `face_blank`와 열린 눈, 닫힌 입이 기본 표시 상태인지 확인합니다.
2. 뒷머리, 얼굴·목, 눈, 입, 앞머리에 ArtMesh를 만듭니다. 통짜 몸은 단순 메쉬로 두고 머리 쪽에 디포머를 집중시킵니다.
3. 머리 회전 디포머 안에 얼굴/눈/입/앞머리 디포머를 넣습니다. 목 아랫부분을 회전 축으로 고정하고, Angle X/Y는 처음에 -12/0/12, Angle Z는 -6/0/6의 작은 범위로 잡습니다. ±X와 ±Y 결합 상태에서 층 사이에 빈틈이 없는지 확인합니다.
4. 눈 뜸/감음과 입 닫힘/열림을 각각 `ParamEyeLOpen`·`ParamEyeROpen`, `ParamMouthOpenY`에 연결합니다. 현재 눈 그림은 양쪽이 한 레이어이므로 좌우 독립 깜빡임은 추가 분리가 필요합니다. 한 번에 깜빡이는 모델이라면 그대로 사용할 수 있습니다.
5. 리본과 뒷머리는 작은 진폭의 물리 흔들림을 지정하고, 텍스처 아틀라스를 만든 다음 `.moc3`/`.model3.json`/`.physics3.json`을 내보냅니다.

## 이미지 생성 지시문 요약

- 뒷머리: 기존 캐릭터의 흰 장발과 붉은 리본을 독립적으로 다시 그리되, 얼굴과 목 뒤에 숨는 안쪽 모발까지 빈 공간 없이 그린다. 배경은 투명하게 한다.
- 얼굴·목: 기존 얼굴의 붉은 눈, 인상, 귀, 턱, 두피와 셔츠 칼라 뒤로 들어갈 긴 목을 완성형으로 그린다. 머리카락과 옷은 제외한다.
- 앞머리: 흰색 층진 머리와 양쪽 얼굴 옆 머리카락을 별도 투명 그림으로 그린다. 얼굴·목·리본·옷은 제외한다.
- 몸체: 검은 전술복, 파란 넥타이, 완장 로고, 훈장, 장갑, 바지, 부츠를 한 장의 정면 그림으로 그린다. 머리·목·머리카락은 제외한다.
- 민얼굴: 동일한 얼굴·목 그림을 유지하고 눈, 눈썹, 속눈썹, 입과 입술만 자연스러운 피부 음영으로 다시 채운다. 뚫린 자국이나 지운 흔적은 만들지 않는다.
