# 펜타 R 컴퍼니 — YouCan v0.4 멀티플레이

## Windows PC에서 서버 열기

1. ZIP 전체를 압축 해제합니다.
2. Node.js 20 이상이 설치된 PC에서 `START-SERVER.bat`를 실행합니다.
3. 서버 창을 켜 둔 상태로 같은 PC에서 Chrome 또는 Edge로 `http://localhost:8080`에 접속합니다.
4. 같은 공유기를 쓰는 친구는 서버 창에 표시된 LAN 주소로 접속합니다. Windows 방화벽 창이 뜨면 사용 중인 개인 네트워크에 대한 액세스를 허용해야 할 수 있습니다.

macOS와 Linux에서는 터미널에서 압축을 푼 폴더로 이동해 `node server.cjs`를 실행합니다. 추가 npm 패키지는 필요 없습니다. 기본 포트는 8080입니다. 포트를 변경하려면 `PORT` 환경 변수를 지정합니다.

## 멀티플레이

- 캐릭터를 선택하고 방을 만듭니다. 친구에게 LAN 주소와 8자리 방 코드를 알려줍니다.
- 친구는 열린 페이지에서 캐릭터를 선택하고 방 코드를 입력해 참가합니다. 방당 1~4인입니다.
- 전원이 **준비**를 누르면 방장이 출격을 시작할 수 있습니다. 다음 출격에도 브리핑에서 다시 준비합니다.
- 우측 상단 **전체 화면** 버튼을 누르면 브라우저 UI까지 숨길 수 있습니다. Esc로 전체 화면을 해제합니다.
- 함선 단말기에 보유 금액, 계약 할당량, 날짜·시간, 적재 수량이 표시됩니다. 회수품 1단위마다 정산 때 1 C를 지급합니다.
- 같은 LAN에서 연결하는 방식입니다. 서로 다른 인터넷 회선에서 플레이하려면 두 PC가 접속할 수 있는 별도의 사설 네트워크가 필요합니다.

## 조작

| 조작 | 키 |
| --- | --- |
| 이동 / 달리기 | WASD 또는 방향키 / Shift |
| 줍기·놓기 / 던지기 | F 짧게 / 길게 눌렀다 놓기 |
| 상호작용·함선 적재 / 콘세타닐 감지 | E / Q |
| 시선 / 인벤토리 칸 | 마우스 / 휠 |
| 공격 / 방어 | 좌클릭 / 우클릭 유지 |
| 고유 능력 / 이륙 | G / 방장이 함선에서 R |

함선 이륙 후 방장이 다음 브리핑을 엽니다. 서버를 종료하면 해당 서버의 방과 진행 기록이 초기화됩니다.
