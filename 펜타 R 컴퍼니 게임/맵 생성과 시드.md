# 펜타 R 컴퍼니 | 맵 생성과 시드

출격할 때마다 폐기 시설의 평면도와 회수품 배치를 시드로 생성한다. 같은 종류의 장소는 하나의 연결된 구역으로 묶는다. 사무실은 회의실·자료실과, 생산실은 가공실·포장실과 이어진다. 처음 방문한 시설에서도 방의 용도를 보고 다음에 어디가 나올지 짐작할 수 있다.

## 1. 구역 인접 규칙

| 구역 | 함께 배치하는 방 | 연결 원칙 |
| --- | --- | --- |
| 착륙·출입 | 착륙장, 적재선, 로비 | 비행선과 시설 내부를 잇는 시작 구간이다. |
| 생산 | 가공실, 생산라인, 포장실 | 서로 직접 연결하거나 생산 전용 통로를 공유한다. |
| 사무 | 사무실, 회의실, 문서고 | 사무 구역 내부에서 오갈 수 있게 묶는다. |
| 물류 | 검수실, 창고, 적재 통로 | 짧은 화물 운반로를 두고 착륙·출입 구역 또는 그와 이어진 공용 통로에 붙인다. |
| 설비 | 기계실, 배전실, 코어실 | 코어실은 설비 구역에 두고, 구역 입구는 생산 구역이나 공용 연결로에 붙인다. |

- **인접의 기준은 통행 가능한 연결**이다. 방끼리 문으로 직접 이어지거나 같은 구역의 전용 복도로 연결돼야 한다. 벽 너머에 맞닿아 있거나 모서리를 접하는 경우는 통행 연결로 세지 않는다.
- 동일 유형의 방을 하나의 구역에 배치한다. 검사할 때는 해당 유형의 방과 그 구역의 전용 복도만으로 경로를 찾는다. 공용 복도나 다른 유형의 방을 거쳐야만 서로 닿는다면 배치를 다시 만든다.
- 같은 층에서는 구역을 인접한 격자 칸으로 키운다. 서로 다른 구역은 경계의 출입문, 교차로, 공용 통로에서 잇는다. 여러 층이 추가되면 같은 유형 전용 계단이나 승강 통로도 연결로 인정한다.
- 여러 건물이 등장하는 시설에서는 건물 규모에도 같은 원칙을 적용한다. 공장동은 생산 구획에, 사무동은 사무 구획에 이웃하게 배치한다. 내부 방 역시 건물별로 유형을 묶는다. 첫 구현은 YouCan 단일 건물·단일 층이다.

## 2. 시드와 재현

- 새 계약을 만들 때 64비트 **계약 시드**를 자동 발급한다. 브리핑에서 **맵 시드**를 복사하거나 디버그·시드 플레이에서 직접 입력할 수 있다. 시드는 앞의 0까지 보존하는 16자리 16진수 문자열로 표시한다.
- 일반 출격 시 맵 시드는 계약 시드, 일차 번호, 시설 ID를 정해진 순서로 조합해 파생한다. 직접 입력한 맵 시드는 해당 출격에 그대로 쓴다. 같은 날 출격을 다시 불러오면 저장된 시드를 재사용한다.
- 재현에 쓰는 값은 **시설 ID + 맵 시드 + 생성기 버전**이다. 같은 세 값은 솔로와 온라인에서 같은 방·문·복도·초기 화물·카메라·위협 시작 지점을 만든다. 플레이 도중의 개념체 반응은 플레이어 행동에 따라 달라진다. 같은 시설의 다른 시드는 구역 위치와 크기, 내부 연결 또는 물자 배치에 변화를 준다.
- 구현 시 해시와 난수 알고리즘, 정렬 기준, 템플릿 목록을 버전으로 고정한다. 기하 배치, 화물, 설비, 위험 요소에는 각각 독립된 파생 난수열을 사용한다. 화물 수치 조정으로 방 배치까지 바뀌는 상황을 줄일 수 있다. 온라인에서는 호스트가 맵 시드와 생성 버전, 결과 체크섬을 공유하며 버전 또는 체크섬이 다른 경우 출격 전에 동기화 오류를 표시한다.

## 3. 생성 순서

1. **시설 템플릿을 선택한다.** 시설별로 필수 구역, 구역별 방 목록, 최소·최대 방 수와 필수 연결을 지정한다. YouCan의 필수 구역은 착륙·출입, 생산, 물류, 설비다. 사무는 선택 구역이다.
2. **구역 단위의 동선을 먼저 정한다.** YouCan은 로비에서 짧은 물류 경로와 우회할 수 있는 생산 경로가 갈라지고, 두 경로가 서로 다른 방향에서 설비 구역에 접근한다. 생산 쪽에서 로비로 돌아오는 우회로를 유지한다. 코어실은 추가 이익을 노릴 때 들어가는 방이다.
3. **구역을 붙여 만들고 내부를 채운다.** 착륙장을 기준으로 서로 겹치지 않는 구역들을 배치한다. 구역마다 출입구가 있는 칸에서 상하좌우로 인접한 빈 칸을 골라 늘린다. 방의 출입구를 맞추고 같은 용도끼리 연결한 뒤, 구역 사이의 공용 출입문과 복도를 잇는다.
4. **화물·설비·위협을 배치한다.** 고가 코어 파편은 설비 쪽에, 저위험 소형 화물은 창고와 생산 통로에 둔다. 창고 관리자는 물류 구역에서 활동을 시작한다. 조각상은 입구에 바로 닿지 않는 지점에서 시작한다. CCTV와 통신 음영은 미리 지정한 후보 중에서 뽑는다. 같은 화물의 확정 수율은 생성 시 결정하고 정산에서 공개한다.
5. **경로를 검사하고 실패하면 재시도한다.** 시드와 시도 번호로 다음 배치를 결정한다. 최대 **16회** 생성해도 모든 조건을 만족하지 못하면, 해당 시설에 준비한 검증용 평면도 중 하나를 시드로 선택한다. 대체 평면도에서도 조건을 만족하는 등록된 배치만 사용한다.

## 4. 출격 가능 판정

- 모든 필수 구역이 착륙장에서 도달 가능하며, 같은 유형의 방은 해당 구역 안에서 전부 연결된다. 필수 보안문은 기본 캐릭터가 현장 패널을 조작해 열 수 있다.
- 코어실을 건너뛰고도 기본 회수품을 적재선으로 운반할 수 있다. 양손 화물이 지나갈 폭을 확보하고, 중간에 내려놓고 문을 조작할 공간이 있다.
- 창고 쪽과 생산 쪽을 모두 탐사한 뒤 돌아갈 수 있는 경로가 있고, 주요 경로의 왕복 시간은 기존 07:00~22:00 근무 시간에 맞춰 검사한다. 착륙·적재선에는 적의 초기 위치를 두지 않는다.
- YouCan의 안전 경로 회수품은 시험값으로 일차당 최소 **40단위**를 배치한다. 최소 보장은 획득 가능한 물량 기준이다. 3일 할당량의 실제 달성률은 솔로와 협동 테스트에서 조정한다.

## 5. 플레이테스트 기준

| 확인 항목 | 통과 조건 |
| --- | --- |
| 재현 | 같은 시설 ID·맵 시드·생성기 버전으로 재실행해 평면도와 초기 배치 체크섬이 일치한다. 솔로와 호스트·참가자 결과도 같다. |
| 변주 | YouCan의 고정 시험 시드 20개에서 방 위치, 진입 순서 또는 우회로가 다른 여러 평면도를 확인한다. |
| 응집 | 여러 시드와 대체 평면도에서 사무·생산·물류·설비 각각의 구역 내부 연결 검사를 통과한다. |
| 운반·철수 | 기본 캐릭터가 코어실을 우회해 회수품을 싣고 귀환할 수 있으며, 중량 화물은 문과 굽은 통로를 통과할 수 있다. |
| 실패 처리 | 의도적으로 잘못된 배치를 넣었을 때 재시도 횟수 제한이 적용되고, 같은 시드로 같은 검증용 평면도가 나온다. |
